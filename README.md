## Что это

**WinCleaner** — программа для Windows, которая убирает мусор, ускоряет систему и отключает навязчивую рекламу
и слежку Windows. Её главное отличие от обычных «чистильщиков»: **перед каждым изменением она запоминает ваше
исходное значение**, поэтому любое действие можно отменить в разделе «Восстановление».

- 🧹 **Безопасная очистка:** только известные места, перед удалением вы видите список файлов и можете исключить любой.
- ↩️ **Всё обратимо:** возвращается именно ваше прежнее значение, а не «настройки по умолчанию».
- 🔒 **Приватность:** никакой рекламы, телеметрии и сетевых запросов, всё работает локально.
- 🎛 **Вы решаете:** ничего не применяется само, каждое действие выбирается галочкой и подтверждается.
- 🌐 **Русский и английский** без перезапуска, тёмная и светлая темы.

## Как пользоваться

1. Запустите программу. Права администратора для старта не нужны.
2. Откройте **«Очистку мусора»**, отметьте категории и нажмите **«Сканировать»**.
3. Просмотрите найденное, уберите галочки у файлов, которые нужно оставить, и нажмите **«Очистить выбранное»**.
4. В **«Оптимизации»**, **«Приватности»** и **«Играх»** отметьте нужные настройки и нажмите **«Применить выбранное»**.
5. Передумали? Откройте **«Восстановление»** и верните прежние значения.

Часть функций (системные журналы, кэш Windows Update, брандмауэр, UAC, обновления) требует прав администратора.
Без них такие пункты пропускаются, а кнопка **«Перезапустить от администратора»** запускает программу заново
с нужными правами, только когда вы сами это выбрали.

## Безопасность

- Файлы удаляются **только внутри списка разрешённых папок**, и путь проверяется заново прямо перед удалением:
  без ссылок и точек соединения (junction), без защищённых папок. Системные файлы Windows, драйверы и реестр не «чистятся».
- Программа меняет **только параметры реестра из своего списка** (`catalog.py`). Подделанная резервная копия,
  которая пытается записать что-то другое, отклоняется при импорте и при восстановлении.
- Перед каждым изменением на диск сохраняется исходное значение. Если применение прервалось, уже сделанное откатывается.
- Нет сетевого кода, нет рекламы, нет телеметрии. Исходный код открыт: можно проверить самому.

## Вопросы и ответы

<details>
<summary><b>Это безопасно?</b></summary>

Программа не делает ничего скрытого: изменения применяются только после вашего подтверждения, сохраняют исходное
значение и обратимы. Всё же она меняет настройки Windows, поэтому используйте её осознанно и на свой риск.
Для первого знакомства применяйте безопасные пункты, например «Показывать расширения файлов», и проверьте, как работает возврат.
</details>

<details>
<summary><b>Почему Windows или антивирус предупреждают о программе?</b></summary>

Файл не подписан цифровой подписью (подпись стоит денег и доступна не всем авторам), поэтому SmartScreen показывает
предупреждение для любой малоизвестной программы. Кроме того, чистильщики по природе удаляют файлы и меняют реестр,
а сборка через PyInstaller иногда вызывает ложные срабатывания антивирусов. Что можно сделать: сверить файл с
`SHA256SUMS.txt`, проверить его на [VirusTotal](https://www.virustotal.com/), прочитать исходный код или собрать программу самостоятельно.
</details>

<details>
<summary><b>Как отменить сделанные изменения?</b></summary>

Раздел **«Восстановление»**: выберите запись и нажмите «Восстановить выбранное», либо восстановите последнюю сессию
или всё сразу. Страницы «Оптимизация», «Приватность» и «Игры» тоже имеют кнопку возврата для своих настроек.
Удалённые файлы очистки вернуть нельзя (кроме тех, что остались в корзине), поэтому перед очисткой смотрите список.
</details>

<details>
<summary><b>Чем отличаются установщик и портативная версия?</b></summary>

| | Установщик | Портативная |
|---|---|---|
| Установка | нужна | не нужна |
| Данные (настройки, история) | `%APPDATA%\WinCleaner` | папка `data` рядом с программой |
| «Запускать вместе с Windows» | доступно | недоступно |
| Запись в профиль пользователя | да | нет |

Перед удалением портативной папки отмените свои изменения в «Восстановлении»: настройки Windows сами не вернутся.
</details>

<details>
<summary><b>Нужны ли права администратора?</b></summary>

Для запуска нет. Для системных категорий очистки и некоторых настроек да: тогда нажмите
«Перезапустить от администратора». Пункты, которым права нужны, без них просто пропускаются.
</details>

<details>
<summary><b>Куда сохраняются настройки и история?</b></summary>

Установленная версия: `%APPDATA%\WinCleaner`. Портативная: папка `data` рядом с программой. Кнопка
«Открыть папку данных» есть в разделе «Настройки». При удалении через установщик программа спросит, удалять ли их.
</details>

<details>
<summary><b>Отправляет ли программа данные в интернет?</b></summary>

Нет. В ней нет сетевого кода, рекламы и телеметрии, всё работает на вашем компьютере.
</details>

## Сборка из исходников

Нужны Windows, **Python 3.11** и (для установщика) бесплатный [Inno Setup 6](https://jrsoftware.org/isdl.php).

```
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py                  :: запуск из исходников

build.bat                         :: портативный ZIP + установщик  ->  папка release
build.bat portable                :: только ZIP
build.bat installer               :: только установщик
build.bat diagnose                :: что найдено и чего не хватает
```

Скрипт сам создаёт окружение, запускает тесты, собирает программу через PyInstaller и пишет журнал в
`release\build.log`. Версия берётся из `version.py`. Режим «портативный» включается файлом `portable.flag`
рядом с `WinCleaner.exe`.

### Тесты

```
py -3.11 -m unittest discover -s tests
```

Автотесты покрывают очистку и безопасность путей, движок настроек, восстановление, автозагрузку, режимы
portable/installed и сборку. Реестр, `powercfg`, `netsh` и внешний вид окна проверяются вручную на Windows 8.1, 10 и 11.
