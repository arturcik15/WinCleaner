# WinCleaner by Art  (v1.0.0)

Windows cleaner & system optimizer. Interface: English / Русский (switch without restart), dark and light theme.
**Windows 8.1, 10, 11** (x64; x86 builds from a 32-bit Python). No ads, no telemetry, no network access.

## Две версии / Two editions

| | Портативная (ZIP) | Установочная (Setup.exe) |
|---|---|---|
| Установка | не нужна, распаковать и запустить | обычный установщик, ярлыки, удаление через «Программы и компоненты» |
| Где хранит данные | папка `data` рядом с программой | `%APPDATA%\WinCleaner` |
| Запись в реестр профиля | нет | только если включить «Запускать с Windows» |
| «Запускать с Windows» | недоступно | доступно |
| Права администратора | только по запросу внутри программы | то же; установка по умолчанию для текущего пользователя |
| Признак режима | файл `portable.flag` рядом с `WinCleaner.exe` | файла нет |

Обе версии собираются из одного кода одной командой.

## Сборка (на Windows)

1. Установите **Python 3.11** (python.org, с «py launcher»).
2. Для установщика один раз установите бесплатный **Inno Setup 6** (https://jrsoftware.org/isdl.php).
3. В папке проекта запустите:

```
build.bat                 :: портативный ZIP + установщик
build.bat portable        :: только ZIP        (или build_portable.bat)
build.bat installer       :: только установщик (или build_installer.bat)
build.bat all --skip-tests
```

Скрипт сам создаёт окружение `.venv-build`, ставит зависимости, запускает автотесты, собирает программу
через PyInstaller (папка `dist\WinCleaner`) и кладёт результат в `release\`:

```
release\WinCleaner-1.0.0-portable-x64.zip
release\WinCleaner-1.0.0-setup-x64.exe
release\SHA256SUMS.txt
```

Версия берётся из `version.py`. Для 32-битной сборки (x86) выполните `build.bat` с 32-битным Python 3.11.
Сборка вручную: `python -m PyInstaller --noconfirm --clean WinCleaner.spec`.

## Запуск из исходников

```
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py
```

## Тестирование

Автотесты (не требуют Windows-интерфейса): `py -3.11 -m unittest discover -s tests`
(очистка и безопасность путей, движок настроек, восстановление, автозагрузка, режимы portable/installed, сборка).

Ручная проверка на каждой системе (8.1 / 10 / 11), отмечайте результат:

- [ ] Запуск, смена языка и темы, значки меню, галочки в списках
- [ ] Главная: версия, сборка, CPU, GPU, RAM, диск совпадают с системой
- [ ] Очистка: Scan -> список файлов -> исключить файл -> Clean (проверить, что исключённый файл остался)
- [ ] Очистка без прав администратора пропускает системные категории; «Перезапустить от администратора» работает
- [ ] Оптимизация: применить 1-2 безопасные настройки (например «Показывать расширения файлов»), убедиться в эффекте
- [ ] Восстановление: вернуть настройку, значение совпало с исходным; экспорт/импорт копии
- [ ] Приватность и Игры: «Проверить», применить, вернуть
- [ ] Автозагрузка: отключить и включить запись, программа не удалена
- [ ] О системе: данные полные, названия без «кракозябр»
- [ ] Портативная: данные в `data`, в `%APPDATA%\WinCleaner` ничего нет
- [ ] Установщик: установка, ярлык, запуск, удаление (вопрос об удалении данных)

## Что реализовано

- **Очистка:** 24 категории (временные файлы, кэш Windows, кэш браузеров Chrome/Edge/Firefox/Brave/Opera/Vivaldi/Яндекс,
  корзина, журналы и дампы, прочее), настоящее потоковое сканирование с остановкой, исключение файлов, подтверждение,
  отчёт; кэш DNS отдельной кнопкой. Пароли, cookies, история, закладки и сессии браузеров не затрагиваются.
- **Оптимизация:** схемы питания, визуальные эффекты, анимации, фоновые приложения, Проводник, меню, быстрый запуск,
  службы (короткий фиксированный список, только «Авто» -> «Вручную»), рекомендации и подсказки Windows.
- **Безопасность (по явному выбору):** отключение брандмауэра, UAC и обновлений Windows — отдельная группа с красным
  предупреждением, ничего не отмечено заранее, всегда дополнительное подтверждение, полностью обратимо.
- **Приватность:** реклама, диагностика (сокращение, не «полное отключение»), рекомендации, фоновая активность.
- **Игры:** Game Mode, фоновая запись, Game DVR, полноэкранная оптимизация, ускорение мыши, аппаратное планирование GPU.
- **Автозагрузка:** реестр (Run, Run32) и папки автозагрузки, издатель, включение/отключение без удаления программ.
- **Восстановление:** перед каждым изменением сохраняется исходное значение; история, восстановление выбранного /
  последней сессии / всего, экспорт и импорт (импорт принимает только известные параметры).
- **О системе:** редакция, сборка, CPU, RAM, GPU, диски (SSD/HDD), DirectX, BIOS/UEFI, сетевые адаптеры.

## Ограничения по версиям Windows

| Функция | 8.1 | 10 | 11 |
|---|---|---|---|
| Очистка, автозагрузка, восстановление, О системе | да | да | да |
| Большинство рекомендаций / рекламных настроек | нет (Not Supported) | да | да |
| Кэш оптимизации доставки | нет | да | да |
| Ultimate Performance | нет | 1803+ | да |
| Журнал действий | нет | 1709+ | да |
| Аппаратное планирование GPU | нет | 2004+ и поддержка GPU/драйвера | да |
| Рекомендации в «Пуске» | нет | нет | 22H2+ |

Windows 7 и 8.0 не поддерживаются (программа сообщит об этом и закроется).

## Безопасность и честные оговорки

- Удаляются только файлы внутри белого списка путей; перед каждым удалением путь проверяется заново
  (без ссылок/junction, без защищённых папок). Системные файлы, драйверы и реестр не очищаются.
- Параметры реестра, которые программа может менять и восстанавливать, ограничены списком в `catalog.py`.
- Часть ключей реестра различается между сборками Windows, а политики (телеметрия, журнал действий) полностью
  работают в Pro/Enterprise. Эффект игровых настроек не гарантируется (FPS не обещается).
- Программа не подписана цифровой подписью: SmartScreen/антивирус могут показать предупреждение при первом запуске.
- На чистой Windows 8.1 может понадобиться обновление KB2999226 (Universal C Runtime).
- Перед удалением портативной версии отмените изменения в «Восстановлении»: они не откатываются сами.
